01 · Problem

One number moved

0.69 → 0.85

Cho/Cr, six months apart. Did the tissue change, or did the measurement?

one synthetic brain one 20 mm frontal voxel two sessions primary variable named before looking: Cho/Cr

Cho/Cr is the choline peak divided by the creatine peak in one small cube of tissue. It went from 0.69 to 0.85. We named Cho/Cr as our main variable before we looked at the follow-up, so we cannot pick whichever number happens to move.

The fit is 60 percent of the error budget, so the cheapest fix is a better shim. The region volume packet claimed 4 percent uncertainty, but its own 1.1 millimetre alignment error implies 19 percent. We caught that, and with 19 percent the volume change is not significant. Valid JSON is not proof, so we went back to the source files and checked.

05 · Next evidence

Next: re-shim and repeat

4.1 min of scanner time

We recommend evidence, never treatment. Re-shim and repeat costs about four minutes, gains the most per minute, and removes the cause of the warning. If nothing changed, the repeat should land between 0.61 and 0.88. A value outside that range means the change is real.

We did not assume the twin is right. We wrote 250 follow-up scans where we know the true answer, spoiled them in known ways, and counted. The error bars hold the truth 93 percent of the time. Doubling the variance for warnings is on the safe side: the data supports 1.4. Broken packets are rejected with a reason and never crash the app.

The dossier's ladder runs from a plain viewer to a twin that steers the next measurement. We keep a saved belief and update it only with checked evidence: level 3. We predict the range of a clean repeat: level 4. We rank what to measure next, and when the repeat arrives the open question closes and the advice changes: level 5. Everything here is synthetic and has no clinical meaning. The drift we allow over six months is an assumption that test-retest data should replace. We declare our AI use: Claude wrote code and first drafts to our direction, and we did not take its output on trust, because automatic tests check every number against the dossier.
